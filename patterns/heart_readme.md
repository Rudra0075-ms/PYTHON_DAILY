# ❤️ Python Turtle Heart

## Simple Explanation

  Code                 Meaning
  -------------------- ----------------------------
  `import turtle`      Imports Turtle
  `Turtle()`           Creates the drawing pen 🐢
  `Screen()`           Creates the window
  `bgcolor('black')`   Black background
  `fillcolor('red')`   Red heart
  `begin_fill()`       Starts filling
  `left()` / `lt()`    Turns left
  `fd()`               Moves forward
  `circle()`           Draws curves
  `end_fill()`         Finishes filling
  `hideturtle()`       Hides the turtle
  `done()`             Keeps window open

## 🧠 Logic

**Setup → Set Colors → Start Fill → Draw Lines & Curves → Fill Heart →
Finish**

## ❤️ Shape Flow

``` text
Start
  ↓
Turn + Draw Line
  ↓
Draw Left Curve
  ↓
Turn
  ↓
Draw Right Curve
  ↓
Draw Bottom Line
  ↓
Fill Red ❤️
  ↓
Finish
```
