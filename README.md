## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/Rudra0075-ms/PYTHON_DAILY.git
   cd PYTHON_DAILY
   ```
2. Run a Python file (example):
   ```bash
   python 02_Numbers/prime_number.py
   ```
3. Open `.ipynb` notebooks with Jupyter Notebook, JupyterLab, or Google Colab.

## Requirements

- Python 3
- Jupyter Notebook/JupyterLab for notebooks
- NumPy and Pandas for the data-library examples

Install the optional data libraries with:
```bash
pip install numpy pandas
```

Most scripts use Python's standard library and can be run independently. Some exercises ask for terminal input.
